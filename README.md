# Sports Pool OS

[![tests](https://github.com/OptimusDigitalSuite/sports-pool-os/actions/workflows/test.yml/badge.svg)](https://github.com/OptimusDigitalSuite/sports-pool-os/actions/workflows/test.yml)

Phone-first NFL pick'em app for a real weekly pool: invites, picks, live standings and a payout ledger. Next.js, React, TypeScript, Supabase, Vitest.

The test suite (473 tests in 48 files) runs on every push. Live app: https://sports-pool-os.vercel.app

Built by Bill Campbell with AI coding agents (Claude Code, Codex): I direct, test, fix and ship.
